# Tanay Lavingia - Mechanical Engineering Portfolio

Ready-to-publish static website for GitHub Pages.

## Live URL after publishing

`https://tanaylavingia.github.io/`

## Repository name

Because the GitHub username is `TanayLavingia`, GitHub requires the user-site repository name to be lowercase:

`tanaylavingia.github.io`

## Main files

- `index.html` - homepage
- `experience.html` - Fresenius, 3Brothers Machination and Siemens Energy
- `projects.html` - academic and technical projects
- `full-portfolio.html` - all 36 portfolio slides
- `assets/css/styles.css` - engineering-theme appearance
- `assets/js/main.js` - mobile menu and image lightbox
- `assets/documents/` - resume and full portfolio PDF, both without a phone number

## Editing basic text

Open an HTML file in Visual Studio Code. Text appears between tags, for example:

```html
<h2>Selected engineering experience and projects</h2>
<p>This is a paragraph.</p>
```

Change only the words between the opening and closing tags. Save the file, then commit and push the change with GitHub Desktop.

## Privacy

The public website does not display a phone number. The resume and portfolio PDF in `assets/documents` were also prepared without a phone number.
